# **Technical Specification: Deep Value Overlay (DVO) System**

**Version:** 1.0
**Target Broker:** Tastytrade
**Core Logic:** Long-Dated Put Writing (Portfolio-Secured) + LEAPS Recycling
**Risk Profile:** Leveraged, Directional, Deep Value

***

## **1. System Architecture \& Modules**

The system operates as an **overlay** on an existing portfolio. It does not replace core holdings but manages a specific "sleeve" of margin-utilizing positions.

### **Modules**

1. **`DataIngest`**: Fetches real-time price, IV, and fundamental data (EPS, Revenue) via Perplexity/Financial APIs.
2. **`GravityEngine`**: The core valuation model. Calculates the "EPS Line" (Intrinsic Value) and current deviation (Mispricing %).
3. **`RegimeClassifier`**: Determines if the market is in `Accumulation`, `Markup`, `Distribution`, or `Decline`.
4. **`RiskGuardian`**: Hard-coded margin limits and exposure caps.
5. **`TradeExecutor`**: Manages complex order routing (Limit orders on illiquid LEAPS) via Tastytrade API.

## **4. Decision Logic \& Workflow (Pseudocode)**

This logic must be implemented in the `TradeExecutor` service.

### **4.1. Entry Logic: "The Gravity Check"**

```python
def check_entry_conditions(symbol, portfolio_state):
    # 1. Get Fundamental Data
    valuation = GravityEngine.analyze(symbol)
    
    # 2. Hard Filter: Is it actually cheap?
    # We only sell puts if price is BELOW the EPS trend line
    if valuation.margin_of_safety < 0.15: 
        return "REJECT: Insufficient Margin of Safety (Not cheap enough)"

    # 3. Macro Filter: Are we catching a falling knife or in a depression?
    regime = RegimeClassifier.get_current()
    if regime == "CRASH_MOMENTUM":
        return "WAIT: VIX > 40, wait for stabilization"
        
    # 4. Collateral Check (The "Portfolio Secured" part)
    # Ensure we don't leverage > 1.5x of Net Liq
    current_leverage = portfolio_state.maintenance_margin / portfolio_state.net_liquidity
    if current_leverage > 0.60:
        return "REJECT: Portfolio margin usage too high"
        
    return "APPROVE_ENTRY"
```


### **4.2. Strategy Selection: Put vs. Combo**

```python
def select_structure(valuation, iv_rank):
    # Scenario A: High Fear, Deep Value

            "strike": "20% OTM",

        }

        return {
            "primary": "SELL_PUT_LEAPS",
            "strike": "15% OTM",
            "dte": "12 Months",
            "secondary": "NONE" # Keep premium as buffer/cash
        }
```


### **4.3. Position Management (The "Hold" logic)**

* **Profit Taking:**
    * If `Unrealized Profit > 50%` AND `DTE > 180 days`: **CLOSE**. (Velocity of money check).
    * If `Price > EPS Gravity Line`: **CLOSE \& ROTATE** (The stock is no longer value).
* **Defense (The "Test"):**
    * If `Price drops 20%` BUT `EPS Gravity Line is flat/rising`: **DO NOTHING**. (Thesis holds, price is wrong).
    * If `Price drops` AND `EPS Gravity Line drops` (Fundamentals broken): **CLOSE LOSS**.
